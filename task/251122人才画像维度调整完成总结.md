## 🔄 数据钩稽关系

### 修改后的钩稽关系

```
员工端: 角色类型 → 专业序列 → 联系邮箱
         ↓           ↓
专家端: 角色类型 ↔ 专业序列（模拟测试）
         ↓           ↓
知识库: tag_role_type ↔ tag_sequence
         ↓           ↓
文档列表: 角色标签 → 序列标签（显示）
```

### 钩稽关系说明

1. **员工端 → 专家端**：员工填写的画像信息会影响专家端的模拟测试
2. **员工端 → 知识库检索**：用户画像会影响文档检索时的标签匹配
3. **专家端上传 → 知识库标签**：专家上传文档时选择的标签会用于后续检索
4. **知识库 → 文档列表**：文档列表显示的标签来自知识库的tag字段
5. **专家端模拟 → 检索效果**：专家调整模拟画像会影响RAG检索的效果测试
