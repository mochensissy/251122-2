# GitHub推送速查卡 🚀

## ⚡ 快速推送（3种方式）

### 方式1：自动化脚本（推荐）
```cmd
一键推送GitHub.bat
```

### 方式2：快速推送
```cmd
快速推送.bat
```

### 方式3：手动命令
```cmd
git push -u origin main
```

## 🔧 常用命令速查

| 操作 | 命令 |
|------|------|
| 初始化仓库 | `git init` |
| 添加远程仓库 | `git remote add origin <url>` |
| 添加文件 | `git add .` |
| 创建提交 | `git commit -m "消息"` |
| 推送代码 | `git push -u origin main` |
| 检查状态 | `git status` |
| 查看历史 | `git log --oneline` |

## 🚨 常见问题快速修复

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `nothing to commit` | 已提交或无更改 | `git push -u origin main` |
| `Authentication failed` | 认证问题 | 使用Personal Access Token |
| `Repository not found` | 地址错误 | 检查远程仓库URL |
| `LF will be replaced by CRLF` | 换行符警告 | 忽略，不影响推送 |

## 🔐 认证设置

### Personal Access Token（推荐）
1. GitHub → Settings → Developer settings → Personal access tokens
2. 生成token，勾选 `repo` 权限
3. 密码提示时输入token

## ✅ 推送后检查清单

- [ ] GitHub仓库显示完整文件结构
- [ ] README.md显示在首页
- [ ] 最新提交记录可见
- [ ] 重要文件都已上传

## 📁 关键文件推送指南

```
✅ 必推：
├── src/                    # 源码
├── package.json           # 依赖
├── README.md              # 说明
└── .gitignore             # 忽略规则

❌ 不推：
├── node_modules/          # 依赖包
├── dist/                  # 构建输出
└── .env                   # 环境变量
```

| 快速推送.bat | 极简推送 | 简单项目 |

## 🎯 最佳实践

1. **推送前检查**
   ```cmd
   git status
   git remote -v
   ```

2. **合理提交信息**
   - 使用动词开头的现在时
   - 简短描述 + 详细说明
   - 包含具体变更内容

3. **认证安全**
   - 优先使用Personal Access Token
   - 定期更新token
   - 不要在脚本中硬编码密码

## 📱 设备间同步

### 推送代码到新设备
```cmd
# 克隆仓库
git clone <repository-url>

# 或在现有目录拉取更新
git pull origin main
```

### 跨平台兼容性
- Windows: 使用 `.bat` 脚本
- Mac/Linux: 使用 `.sh` 脚本
- 手动命令: 通用支持

```cmd
git push
```
