# 人才画像测评选项更新总结

## 📋 修改概述

根据业务需求，对职业发展AI智能体系统中的人才画像测评选项进行了系统性更新，确保员工端、专家端和知识库管理三个端口的数据钩稽关系同步。

## 🎯 核心变更

### 变更前 → 变更后

| 维度 | 变更前 | 变更后 |
|------|--------|--------|
| **第一项** | 专业序列<br/>（人力资源、财务、信息技术、营销等） | 角色类型<br/>（基层、经理层、专业总监、干部） |
| **第二项** | 职级<br/>（P1-P3、P4-P5、P6-P7、全职级） | 专业序列<br/>（市场（营销）、市场（销售）、供应链（生产）等16个选项） |
| **第三项** | 角色类型<br/>（管理岗、非管理岗） | **删除** |
| **第四项** | 联系邮箱（选填） | 联系邮箱（选填） |

### 专业序列详细列表

**新的专业序列选项（16个）**：
1. 市场（营销）

7. 人力资源

9. 战略管理
10. 行政管理

12. 党群
13. 纪检

## 🔄 数据钩稽关系

### 修改前后对比

```
修改前：
员工端: 专业序列 → 职级 → 角色类型
专家端: 专业序列 ← → 职级 ← → 角色类型  
知识库: 标签序列 ← → 标签职级 ← → 标签角色

修改后：
员工端: 角色类型 → 专业序列
专家端: 角色类型 ↔ 专业序列
知识库: 标签角色 ← → 标签序列
```

### 钩稽关系说明

1. **员工端选择 → 专家端模拟**：员工填写的画像信息会影响专家端的模拟测试
2. **员工端选择 → 知识库检索**：用户画像会影响文档检索时的标签匹配
3. **专家端上传 → 知识库标签**：专家上传文档时选择的标签会用于后续检索
4. **专家端模拟 → 检索效果**：专家调整模拟画像会影响RAG检索的效果测试

## ⚠️ 风险评估

### 高风险项
1. **数据迁移失败**：可能影响现有文档的检索效果
   - **缓解措施**：备份现有数据，分步骤执行迁移

2. **用户画像重置**：现有用户需要重新填写画像
   - **缓解措施**：在界面上明确提示用户重新填写

### 中风险项
1. **文档标签不准确**：历史文档可能需要人工审核和重新标记
   - **缓解措施**：制定文档标签审核流程

2. **检索效果变化**：新的标签结构可能影响检索精准度
   - **缓解措施**：监控检索效果，必要时调整算法
