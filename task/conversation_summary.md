# 对话摘要

- 用户希望 AI 回答更加贴合个人画像、能组合多个政策后再输出，而不是简单粘贴长段文本。在交互过程中，帮助其完成了画像持久化、文档标签管理、通知流程等多个功能点的开发。
- 针对“回答碎片多、像原文堆砌”的痛点，先后对 `RAGChat` 和 `deepseek-client` 做了改造：检索结果加入标签、发送对话历史、强制 DeepSeek 按“画像匹配 → 政策要点 → 建议行动 → 提醒”输出，命中为空时改用 HITL 提示。
- 另外学习到了：用户在专家端未完成画像时无法使用 AI 问答；需要展示命中的标签（序列/职级/角色）让专家核对；当知识库无匹配时要引导联系职业发展 COE 或发起上报。
- 后续仍需优化点：对 chunk 做更精细的句子挑选或高亮命中句、上下文引用更短更精准；DeepSeek 对回答仍有贴原文的倾向，可以继续迭代 Prompt 或在 RAG 层做关键词评分。
